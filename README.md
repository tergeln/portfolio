# Portfolio

Personal portfolio of Tergel Nyamlkhagva: a single static page (`index.html` + `styles.css`), no build step.

## View locally

Open `index.html` in a browser.

## Publish with GitHub Pages

Repository **Settings → Pages → Deploy from a branch → `main` / root**. The site will be served at
https://tergeln.github.io/portfolio/
